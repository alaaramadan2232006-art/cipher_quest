CIPHER QUEST — PINK NEON CYBER EDITION
======================================

WHAT'S DIFFERENT
- Pink and violet cyber security palette (no flowers, no character wallpaper).
- Animated encryption rain, code packets, cipher-core rings, circuit rails, scanline/glitch effects.
- Clear PLAY GAME button and easy-to-read labels.
- The existing 9 puzzle stages and optional Firebase Cloud Portal are retained.
- The game auto-selects the newest .wav, .ogg, or .mp3 file found in this folder or its assets folder.

INSTALL IN YOUR EXISTING GAME FOLDER
1. Keep your current assets/ folder and cloud_config.json. Do not delete them.
2. Copy cipher_quest_pink_cyber.py into G:\CipherQuest.
3. Keep your chosen song in G:\CipherQuest\assets or next to the Python file. The game chooses the newest audio file automatically.
4. Open G:\CipherQuest in VS Code and run:
   .\.venv\Scripts\python.exe cipher_quest_pink_cyber.py

If you do not have .venv yet, install pygame-ce in a Python environment with enough disk space.
Cloud features only work after Firebase is configured; the game does not falsely claim the cloud is connected.
